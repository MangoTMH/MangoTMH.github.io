## GitHub Pages

Target repository: `MangoTMH/MangoTMH.github.io`

Target URL after successful deployment: https://mangotmh.github.io/

1. Create a **public** repository named `MangoTMH.github.io` under `MangoTMH`, if it does not already exist.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside a `portfolio` folder. Include `.nojekyll`.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for the Pages deployment to succeed before using the URL in applications.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Future commits to the publishing branch automatically update the website.
